# Accessibility Rules

- Use semantic HTML elements whenever possible.
- Add Labels to all form inputs.
- Use descriptive button text.
- Do not use color alone to communicate important information.
- Maintain readable color contrast
- Esure interactive elements can be used with a keyboard.
- Include meaningful text for loading, success, and error states.
- Add appropriate alternative text to meaningful images.
- Preserve visible focus states.
- Use accessible modal and menu behavior.
