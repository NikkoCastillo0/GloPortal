# Tailwind CSS Rules

- Use Tailwind utility classes for styling whenever possible.
- Follow the existing project colors, spacing, typography, and layout patterns.
- Use responsive classes such as `sm:`, `md:`, and `lg:`.
- Design for mobile screens before larger screens.
- Avoid arbitrary values unless they are necessary.
- Avoid creating new CSS files when Tailwind classes are sufficient.
- Keep related class names organized and readable.
- Reuse consistent button, input, card, and layout styles.
- Do not introduce a new color or font without checking existing project styles.
- Preserve the current visual design unless the task specifically requests a redesign.
