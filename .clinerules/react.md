# React Rules

- Use functional React components.
- Use React hooks when appropriate.
- Keep components focused on one responsibility.
- Reuse existing components before creating new ones.
- Keep complex logic outside the JSX when possible.
- Avoid unnecessary `useEffect` usage.
- Do not duplicate state that can be derived from existing state.
- Preserve existing loading, error, and empty states.
- Use controlled inputs for forms.
- Use React Router patterns already established in the project.
- Add accessible labels to form fields.
- Use descriptive names for components, props, functions, and state variables.
- Do not modify unrelated components or files.
